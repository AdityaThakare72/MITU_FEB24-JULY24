# MITU_FEB24-JULY24

Programs from the MITU batches of February 2024 and July 2024.

## Contents

- `Mitu Feb 2024/`: Python basics, decision making, GUI, NumPy, Pandas, data cleaning and visualization, encoding and scaling; `ML/` covers regression, decision trees, KNN, bagging and boosting, cross validation and tuning, clustering, association rules and ANN
- `MITU JUL 2024/Python/`: basics, decision making, loops, data structures, GUI, NumPy, Pandas and visualization
- `MITU JUL 2024/Machine Learning/`: encoding and feature scaling, linear, multiple and polynomial regression, logistic regression, decision trees, KNN, naive Bayes, SVM, regularization, and ensembles (bagging, boosting, random forest, stacking)

Open the notebooks in Jupyter or Google Colab.
